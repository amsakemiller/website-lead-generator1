# 🚀 Quick Start Guide

## Easy Ways to Run the Lead Generation Tool

### Option 1: Double-Click Batch File (Easiest)
1. **Double-click `run_app.bat`** in this folder
2. The application will start automatically
3. A window will stay open to show any messages

### Option 2: Double-Click Python Launcher
1. **Double-click `start_leadgen.py`** in this folder
2. The application will start with helpful messages
3. More user-friendly error messages

### Option 3: Command Line (Advanced)
1. Open Command Prompt in this folder
2. Type: `python unified_leadgen.py`
3. Press Enter

## 📁 What You'll See

When you start the application, you'll see a popup with three options:

### 🆕 New Run
- Start a fresh lead generation process
- Configure all settings from scratch
- Use the new 8-box keyword system

### 🔄 Continue Run  
- Resume a previous run that was interrupted
- See progress status of all previous runs
- Pick up where you left off

### 📥 Download Leads
- Download all leads ever found (comprehensive)
- Download leads from a specific run
- Data is automatically sorted by quality

## 🎯 Key Features

- **8 Keyword Boxes**: More flexible search combinations
- **Configurable Scoring**: 8 positive + 8 negative factors
- **Smart Thresholds**: Score, percentage, or count-based filtering
- **Comprehensive Logging**: Never lose data, track everything
- **Re-analysis Control**: Skip recently analyzed leads
- **Auto-Save**: Progress saved every 10 websites

## 🆘 Need Help?

If you have any issues:
1. Make sure Python is installed
2. Check that all files are in the same folder
3. Try running `python unified_leadgen.py` in Command Prompt
4. Look for error messages in the terminal

## 📊 Output Files

The application creates several folders:
- `comprehensive_logs/` - All leads ever processed
- `run_logs/` - Individual run data  
- `downloads/` - Your exported CSV files
- `data/` - Temporary processing files
- `logs/` - Detailed run logs

Happy lead generating! 🎉
